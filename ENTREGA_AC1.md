# Entrega 1ª AC — Classroom

Preencha os links e a lista do grupo antes de enviar. **Cada aluno do grupo** deve entregar no Classroom.

## Texto para colar

```
Projeto: Agenda de Contatos
Entrega: 1ª AC — Cadastro e listagem de contatos

Participantes do grupo:
- [Nome completo 1]
- [Nome completo 2]
- ...

Board (lista de funcionalidades):
[colar link do GitHub Projects ou Trello]

GitHub (código fonte):
[colar link do repositório]

Vídeo da funcionalidade:
[colar link Drive / YouTube não listado / anexo]
```

## Roteiro do vídeo (~2–3 min)

1. Abrir o **board** — mostrar as colunas e a lista de funcionalidades.
2. Destacar o card **1ª AC — Cadastro e listagem de contatos** em **Concluído**.
3. Abrir o app em http://127.0.0.1:8000/
4. Cadastrar **2 contatos** em /novo/
5. Mostrar a **lista** atualizada.
6. Abrir o repositório no **GitHub**.
7. Encerrar: “1ª AC — cadastro e listagem de contatos”.

## Publicação do vídeo (sugestão)

- Google Drive (link com permissão de leitura) **ou**
- YouTube com visibilidade **Não listado** **ou**
- Upload direto no Classroom (se o arquivo for leve)
